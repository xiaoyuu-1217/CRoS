# CRoS

### CRoS: Causality Reward on Scrambled CoTs Improves Accuracy and Reasoning Faithfulness

[Xiao Yu](https://github.com/xiaoyuu-1217) · Justin Chih-Yao Chen · Zaid Khan · Hyunji Lee · Mohit Bansal

UNC Chapel Hill

**TL;DR:** **CRoS** (**C**ausality **R**eward **o**n **S**crambled CoTs) proposes a *causality reward* that incorporates the causal relationship between the CoT and the final answer into the outcome reward to improve both accuracy and reasoning faithfulness.
